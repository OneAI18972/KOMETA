# 💖 Альтернативные варианты бота для nikswiq 💖

Я создал для вас несколько вариантов бота без Python! Выберите тот, который вам больше нравится:

## 🚀 1. Node.js (JavaScript) - Рекомендуется

### Установка и запуск:
```bash
# Установить Node.js (если еще не установлен)
# Скачать с https://nodejs.org/

# Установить зависимости
npm install

# Запустить бота
npm start
```

### Преимущества:
- ✅ Простой и понятный код
- ✅ Легко установить
- ✅ Работает как настоящий Telegram бот
- ✅ Красивые кнопки и анимация

---

## 🌐 2. Веб-версия (HTML + JavaScript)

### Запуск:
```bash
# Просто откройте файл в браузере
open web_bot.html
# или
firefox web_bot.html
# или
chrome web_bot.html
```

### Преимущества:
- ✅ Не требует установки
- ✅ Красивый дизайн
- ✅ Работает в любом браузере
- ✅ Анимация сердечек

---

## 🐧 3. Bash скрипт (самый простой)

### Запуск:
```bash
# Сделать исполняемым
chmod +x bot.sh

# Запустить
./bot.sh
```

### Преимущества:
- ✅ Работает везде (Linux, Mac, Windows с WSL)
- ✅ Не требует установки дополнительных программ
- ✅ Цветной вывод в терминале
- ✅ Простая анимация

---

## 📱 Как использовать каждый вариант:

### Node.js бот:
1. Установите Node.js
2. Выполните `npm install`
3. Запустите `npm start`
4. Найдите бота в Telegram и отправьте `/start`

### Веб-версия:
1. Откройте `web_bot.html` в браузере
2. Нажимайте на кнопки
3. Наслаждайтесь анимацией!

### Bash скрипт:
1. Откройте терминал
2. Перейдите в папку с файлом
3. Запустите `./bot.sh`
4. Выбирайте опции цифрами
