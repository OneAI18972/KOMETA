# 📖 Руководство по использованию генератора Roblox аккаунтов

## 🎯 Что делает этот генератор

Этот проект предоставляет два основных функционала:

1. **Генерация данных аккаунтов** - создает логины и пароли без регистрации
2. **Автоматическая регистрация** - реально регистрирует аккаунты на Roblox.com

## 🚀 Быстрый старт

### Шаг 1: Установка
```bash
# Клонируйте репозиторий (если используете git)
git clone <repository-url>
cd roblox-account-generator

# Установите зависимости
npm install
```

### Шаг 2: Простая генерация (без регистрации)
```bash
# Генерация 10 аккаунтов
npm start

# Генерация 50 аккаунтов
node generator.js --count=50
```

### Шаг 3: Автоматическая регистрация
```bash
# Регистрация 1 аккаунта для тестирования
node roblox-register.js --count=1

# Регистрация 5 аккаунтов в фоновом режиме
node roblox-register.js --count=5 --headless
```

## 📋 Подробные инструкции

### 🔧 Генерация данных аккаунтов

#### Базовый генератор:
```bash
# Генерация по умолчанию (10 аккаунтов)
node generator.js

# Генерация определенного количества
node generator.js --count=25

# Генерация с коротким флагом
node generator.js -c=100
```

#### Продвинутый генератор:
```bash
# Игровые логины с сильными паролями
node advanced-generator.js --count=20 --style=gamer --complexity=strong

# Имена с email
node advanced-generator.js -c=10 -s=name -p=medium --email

# Сохранение в JSON формате
node advanced-generator.js --count=5 --format=json

# Сохранение в CSV с email
node advanced-generator.js -c=10 -s=gamer -p=strong --email --format=csv
```

### 🤖 Автоматическая регистрация

#### Безопасная регистрация:
```bash
# Регистрация 1 аккаунта с видимым браузером
node roblox-register.js --count=1

# Регистрация 3 аккаунтов в фоне
node roblox-register.js --count=3 --headless

# Регистрация с задержкой 20 секунд
node roblox-register.js -c=5 -d=20000
```

#### Массовая регистрация (осторожно!):
```bash
# Регистрация 10 аккаунтов с большой задержкой
node roblox-register.js --count=10 --headless --delay=30000

# Регистрация 20 аккаунтов с задержкой 1 минута
node roblox-register.js -c=20 -h -d=60000
```

## 📊 Выходные файлы

### При генерации данных:
- `roblox_accounts.txt` - базовые аккаунты
- `advanced_roblox_accounts.txt` - продвинутые аккаунты
- `gamer_accounts.txt` - игровые логины
- `name_accounts.txt` - имена с email
- `adjective_accounts.txt` - прилагательные
- `json_accounts.json` - JSON формат
- `csv_accounts.csv` - CSV формат

### При автоматической регистрации:
- `roblox_registered_accounts.txt` - зарегистрированные аккаунты
- `detailed_roblox_accounts.json` - детальная информация

## ⚙️ Параметры командной строки

### Базовый генератор:
- `--count=N` или `-c=N` - количество аккаунтов (по умолчанию: 10)

### Продвинутый генератор:
- `--count=N` или `-c=N` - количество аккаунтов
- `--style=TYPE` или `-s=TYPE` - стиль логинов (random, gamer, name, adjective)
- `--complexity=LEVEL` или `-p=LEVEL` - сложность паролей (simple, medium, strong)
- `--email` или `-e` - включить генерацию email
- `--format=TYPE` или `-f=TYPE` - формат сохранения (simple, numbered, json, csv)
- `--display=N` или `-d=N` - количество отображаемых аккаунтов

### Автоматическая регистрация:
- `--count=N` или `-c=N` - количество аккаунтов для регистрации
- `--headless` или `-h` - запуск в фоновом режиме
- `--delay=N` или `-d=N` - задержка между регистрациями (мс)

## 🛡️ Рекомендации по безопасности

### Для генерации данных:
- ✅ Безопасно для использования
- ✅ Не нарушает ToS
- ✅ Можно использовать для тестирования

### Для автоматической регистрации:
- ⚠️ Может нарушать ToS Roblox
- ⚠️ Используйте только для образовательных целей

- ⚠️ Используйте задержки не менее 10 секунд
- ⚠️ Используйте разные IP-адреса при массовой регистрации

## 🎯 Лучшие практики

1. **Начните с малого** - сначала протестируйте с 1-2 аккаунтами
2. **Используйте задержки** - не менее 10 секунд между регистрациями
3. **Мониторьте статистику** - следите за процентом успешности
4. **Сохраняйте логи** - проверяйте файлы с ошибками
5. **Соблюдайте ToS** - используйте только для образовательных целей

## 📞 Поддержка
