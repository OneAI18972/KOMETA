# AniType - Сайт для просмотра аниме

Современный веб-сайт для просмотра аниме с темным дизайном, построенный на React и TypeScript.

## Возможности

- 🎨 Современный темный дизайн
- 🔍 Поиск аниме по названию и жанрам
- 📱 Адаптивный дизайн для всех устройств
- 🎭 Фильтрация по:
  - Статусу (Онгоинг, Завершен, Анонс)
  - Типу (TV, Фильм, OVA, ONA, Спешл)
  - Количеству эпизодов
  - Рейтингу
  - Жанрам
  - Наличию 4K качества
- 📚 Коллекции аниме с горизонтальной прокруткой
- 🎬 Модальные окна с подробной информацией
- ⭐ Рейтинги и значки статуса
- 🚀 Быстрая производительность

## Технологии

- **React 18** - UI библиотека
- **TypeScript** - Типизация
- **Tailwind CSS** - Стили
- **Vite** - Сборщик
- **Lucide React** - Иконки

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите сервер разработки:
```bash
npm run dev
```

3. Откройте браузер и перейдите по адресу: http://localhost:3000

## Структура проекта

```
src/
├── components/          # React компоненты
│   ├── Header.tsx      # Шапка с навигацией и поиском
│   ├── AnimeCard.tsx   # Карточка аниме
│   ├── AnimeGrid.tsx   # Сетка и коллекции аниме
│   ├── FilterSidebar.tsx # Боковая панель фильтров
│   └── AnimeModal.tsx  # Модальное окно с деталями
├── types/              # TypeScript типы
│   └── anime.ts        # Интерфейсы для аниме
├── data/               # Данные
│   └── mockData.ts     # Тестовые данные аниме
├── App.tsx             # Главный компонент
├── main.tsx            # Точка входа
└── index.css          # Основные стили
```

## Сценарии npm

- `npm run dev` - Запуск сервера разработки
- `npm run build` - Сборка для продакшена
- `npm run preview` - Предварительный просмотр продакшен сборки

## Функциональность

### Поиск
- Поиск по русскому и английскому названию
- Поиск по жанрам
- Реальное время поиска без задержек

### Фильтры
- Статус: Анонс, Онгоинг, Завершён
- Тип: TV, Фильм, OVA, ONA, Спешл
- Диапазон эпизодов
- Диапазон рейтингов
- Наличие 4K
- Множественный выбор жанров

### Коллекции
- "Сейчас смотрят"
- "Доступно в 4K"
- "Романтика от ВИ"
- "Sword Art Online (Кайфовое аниме)"
- "Смотри артем"
- "The best"

### Карточки аниме
- Постер с hover эффектами
- Рейтинг с звездочкой
- Значки 4K, статуса и количества эпизодов
- Жанры и основная информация

### Модальные окна
- Детальная информация об аниме
- Кнопка воспроизведения
- Крупный рейтинг
- Полное описание
- Жанры и техническая информация

## Дизайн

Сайт использует темную цветовую схему:
- **Фон**: #0a0a0a (anime-dark)
- **Карточки**: #2a2a2a (anime-card)
- **Серый**: #1a1a1a (anime-gray)
- **Акцент**: #4ade80 (anime-accent)
- **Синий**: #3b82f6 (anime-blue)
