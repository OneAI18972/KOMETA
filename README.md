# 🎮 Генератор Roblox Аккаунтов

Генератор случайных Roblox аккаунтов в формате `логин:пароль` на Node.js.

## 📋 Возможности

- ✅ Генерация случайных логинов и паролей
- ✅ Сохранение в текстовый файл
- ✅ Вывод в консоль
- ✅ Настраиваемое количество аккаунтов
- ✅ Различные паттерны генерации
- ✅ Безопасные пароли с символами

## 🚀 Установка

1. Установите зависимости:
```bash
npm install
```

## 💻 Использование

### Базовое использование (10 аккаунтов по умолчанию):
```bash
npm start
```

### Генерация определенного количества аккаунтов:
```bash
node generator.js --count=50
# или
node generator.js -c=25
```

### Использование как модуль:
```javascript
const RobloxAccountGenerator = require('./generator');

const generator = new RobloxAccountGenerator();
const accounts = generator.run(20, true, true);
```

## 📁 Выходные файлы

- `roblox_accounts.txt` - файл с сгенерированными аккаунтами в формате `логин:пароль`

## 🔧 Настройки

### Паттерны генерации логинов:
- Случайные имена пользователей
- Прилагательное + существительное + число
- Имя + фамилия + число
- Наречие + существительное + число
- Имя + число

### Паттерны генерации паролей:
- Прилагательное + существительное + число + символ
- Имя + число + символ
- Наречие + существительное + число + символ
- Фамилия + число + символ
- Прилагательное + число + символ

## ⚠️ Важные замечания

1. **Только для образовательных целей** - этот генератор создан для изучения Node.js
2. **Не используйте для создания реальных аккаунтов** - это может нарушать условия использования Roblox
3. **Генерируемые данные случайны** - не гарантируется уникальность
