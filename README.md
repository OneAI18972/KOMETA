# 🌐 IP Info Tracker

Веб-приложение и Telegram бот для отображения информации о посетителях, включая IP адрес, местоположение, браузер и другие детали.

## ✨ Возможности

### 🌐 Веб-приложение
- 🌍 Отображение IP адреса посетителя
- 📍 Геолокация по IP (страна, город, координаты)
- 🌐 Информация о браузере и устройстве
- ⏰ Время запроса
- 🔗 API endpoints для получения данных в JSON формате
- 📱 Адаптивный дизайн для мобильных устройств
- 🎨 Современный и красивый интерфейс

### 🤖 Telegram бот
- 📱 Получение информации об IP через Telegram
- 🌍 Геолокация по IP адресу
- 📍 Детальная информация о местоположении
- ⚡ Быстрые команды

## 🚀 Быстрый запуск

### Веб-приложение

1. **Запуск через скрипт:**
```bash
./start.sh
```

2. **Или вручную:**
```bash
python3 app.py
```

Приложение будет доступно по адресу: `http://localhost:5000`

### Telegram бот

1. **Получите токен бота:**
   - Найдите @BotFather в Telegram
   - Отправьте команду `/newbot`
   - Следуйте инструкциям
   - Скопируйте полученный токен

2. **Установите токен в файл `bot.py`:**
```python
BOT_TOKEN = "ваш_токен_здесь"
```

3. **Запустите бота:**
```bash
./start_bot.sh
```

## 📡 API Endpoints

### Полная информация о посетителе
```
GET /api/info
```
Возвращает полную информацию в JSON формате.

### Только IP адрес
```
GET /api/ip
```
Возвращает только IP адрес в JSON формате.

## 🎯 Использование

### Веб-приложение
1. Откройте браузер и перейдите по адресу `http://localhost:5000`
2. Увидите красивую страницу с информацией о вашем подключении
3. Используйте API endpoints для получения данных в JSON формате

### Telegram бот
1. Найдите вашего бота в Telegram
2. Отправьте команду `/start` для начала работы
3. Используйте команду `/ip` для получения информации о вашем IP
4. Или отправьте любой IP адрес для получения информации о нем

## 🔧 Настройка

### Изменение порта веб-приложения
Отредактируйте файл `app.py`:
```python
if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000, debug=True)
```

### Настройка Telegram бота
1. Откройте файл `bot.py`
2. Замените `YOUR_BOT_TOKEN_HERE` на ваш токен
3. При необходимости настройте дополнительные команды

## 📱 Особенности
