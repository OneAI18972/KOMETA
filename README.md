# TRIDNYAHEY 🎌

Минималистичный сайт для просмотра аниме с собственным плеером **Tridnyah**.

## ✨ Особенности

- 🎨 **Современный дизайн** - минималистичный интерфейс в темных тонах с градиентами
- 🎬 **Собственный плеер Tridnyah** - полнофункциональный видеоплеер с кастомным дизайном  
- 🖼️ **Анимированные баннеры** - красивый слайдер с автопрокруткой
- 📱 **Адаптивный дизайн** - отлично работает на всех устройствах
- 🔍 **Поиск в реальном времени** - мгновенный поиск аниме
- 🎯 **Интуитивная навигация** - простая и понятная структура
- ⚡ **Быстрая загрузка** - оптимизированный код и ресурсы

## 🚀 Функциональность

### Главная страница
- Анимированный слайдер с популярными аниме
- Каталог с красивыми обложками и рейтингами
- Секция жанров с иконками
- Поиск по названиям

### Плеер Tridnyah
- Полноэкранный режим
- Управление громкостью
- Выбор эпизодов
- Горячие клавиши (Space - пауза/воспроизведение, Escape - закрыть)
- Кастомные элементы управления

### Дополнительно
- Уведомления о действиях
- Плавная прокрутка
- Эффект параллакса
- Easter egg (Konami code: ↑↑↓↓←→←→BA)

## 🎮 Управление

### Навигация
- **Главная** - возврат на главную страницу
- **Каталог** - прокрутка к каталогу аниме
- **Жанры** - переход к секции жанров
- **Поиск** - фокус на поле поиска

### Плеер
- **Клик по аниме** - открыть в плеере
- **Space** - пауза/воспроизведение
- **Escape** - закрыть плеер
- **Клик по эпизоду** - переключить эпизод

### Слайдер
- **Автопрокрутка** - каждые 5 секунд
- **Стрелки** - ручное переключение
- **Индикаторы** - прямой переход к слайду
- **Пауза при наведении** - остановка автопрокрутки

## 🔧 Настройка

1. Откройте `index.html` в браузере
2. Для добавления нового аниме см. подробную инструкцию в `HOW_TO_ADD_ANIME.md`
3. Для изменения стилей используйте `styles.css`

## 📚 Добавление нового аниме

Подробная инструкция находится в файле `HOW_TO_ADD_ANIME.md`. Кратко:

1. **Добавьте данные** в объект `animeData` в `script.js`:
```javascript
'anime-id': {
    title: 'Название',
    episodes: 24,
    year: '2023',
    rating: 8.5,
    description: 'Описание...',
    cover: 'https://cdn.myanimelist.net/images/anime/xxx/xxx.jpg',
    videoUrl: 'https://video-url.mp4',
    episodes_list: [
        { number: 1, title: 'Эпизод 1', duration: '23:40' }
    ]
}
```

2. **Добавьте карточку** в `index.html` в секцию `anime-grid`

3. **Обновите страницу** - готово!

### 🖼️ Источники обложек:
- **MyAnimeList**: `https://cdn.myanimelist.net/images/anime/...`
- Высокое качество, стандартные размеры
- Просто скопируйте ссылку на изображение
