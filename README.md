# Redti - Торговая площадка для игровых аккаунтов

Современный веб-сайт, похожий на Reddit, для продажи и покупки игровых аккаунтов с фокусом на Roblox.

## Особенности

- 🎨 Современный темный интерфейс
- 📱 Адаптивный дизайн для всех устройств
- 🎮 Специализация на игровых аккаунтах
- 🔍 Функция поиска и фильтрации
- ⭐ Система рейтингов продавцов
- 💬 Возможность связи с продавцами

## Технологии

- React 18
- CSS3 с современными возможностями
- Lucide React для иконок
- Responsive Grid Layout

## Запуск проекта

1. Установите зависимости:
```bash
npm install
```

2. Запустите проект в режиме разработки:
```bash
npm start
```

3. Откройте [http://localhost:3000](http://localhost:3000) в браузере

## Структура проекта

```
src/
├── components/
│   ├── Header.js          # Шапка сайта с навигацией
│   ├── Sidebar.js         # Боковая панель с категориями
│   ├── MainContent.js     # Основной контент
│   ├── GameBanner.js      # Баннер с играми
│   └── AccountCard.js     # Карточка аккаунта
├── App.js                 # Главный компонент
└── index.js              # Точка входа
```

## Функционал

### Основные разделы:
- **Предметы** - Игровые предметы и ресурсы
- **Робуксы** - Внутриигровая валюта Roblox
- **Аккаунты** - Готовые игровые аккаунты
- **Буст** - Услуги по прокачке
- **Игровая валюта** - Различные внутриигровые валюты
- **Roblox Studio** - Ресурсы для разработки

### Карточки товаров содержат:
- Превью изображение
- Название и описание
- Цену или возможность связаться
- Информацию о продавце
- Рейтинг продавца
- Кнопки действий

## Сборка для продакшена
