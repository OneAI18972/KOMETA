# 🎮 Генератор Roblox Аккаунтов с Автоматической Регистрацией

Полнофункциональный генератор Roblox аккаунтов с возможностью автоматической регистрации на сайте Roblox.com.

## 📋 Возможности

### 🔧 Генерация аккаунтов:
- ✅ Генерация случайных логинов и паролей
- ✅ Сохранение в текстовый файл
- ✅ Вывод в консоль
- ✅ Настраиваемое количество аккаунтов
- ✅ Различные паттерны генерации
- ✅ Безопасные пароли с символами

### 🤖 Автоматическая регистрация:
- ✅ Автоматическое заполнение форм на Roblox.com
- ✅ Обход защиты от ботов
- ✅ Множественные селекторы для надежности
- ✅ Статистика успешности регистрации
- ✅ Сохранение зарегистрированных аккаунтов
- ✅ Режим headless для фоновой работы

## 🚀 Установка

1. Установите зависимости:
```bash
npm install
```

2. Убедитесь, что у вас установлен Node.js версии 14+

## 💻 Использование

### Базовый генератор (только генерация данных):
```bash
# Генерация 10 аккаунтов
npm start

# Генерация определенного количества
node generator.js --count=50
```

### Автоматическая регистрация на Roblox.com:
```bash
# Регистрация 5 аккаунтов (с видимым браузером)
npm run register

# Регистрация в фоновом режиме
npm run register-headless

# Регистрация с настройками
node roblox-register.js --count=10 --headless --delay=15000
```

### Продвинутый генератор:
```bash
# С различными стилями и форматами
node advanced-generator.js --count=20 --style=gamer --complexity=strong
node advanced-generator.js -c=50 -s=name -p=simple --email
node advanced-generator.js --count=100 --format=json --display=5
```

## 📁 Выходные файлы

### При генерации:
- `roblox_accounts.txt` - базовые аккаунты
- `advanced_roblox_accounts.txt` - продвинутые аккаунты
- `gamer_accounts.txt` - игровые логины
- `name_accounts.txt` - имена с email
- `adjective_accounts.txt` - прилагательные
- `json_accounts.json` - JSON формат
- `csv_accounts.csv` - CSV формат

### При автоматической регистрации:
- `roblox_registered_accounts.txt` - зарегистрированные аккаунты
- `detailed_roblox_accounts.json` - детальная информация

## 🔧 Настройки автоматической регистрации

### Параметры командной строки:
- `--count=N` или `-c=N` - количество аккаунтов для регистрации
- `--headless` или `-h` - запуск в фоновом режиме
- `--delay=N` или `-d=N` - задержка между регистрациями (мс)

### Примеры команд:
```bash
# Регистрация 3 аккаунтов с видимым браузером
node roblox-register.js --count=3

# Регистрация 10 аккаунтов в фоне с задержкой 20 секунд
node roblox-register.js --count=10 --headless --delay=20000

# Быстрая регистрация 1 аккаунта для тестирования
node roblox-register.js -c=1 -d=5000
```

## 🛡️ Особенности безопасности

### Обход защиты:
- Случайные задержки между действиями
- Реалистичные User-Agent заголовки
- Блокировка ненужных ресурсов (изображения, CSS)
- Множественные селекторы для надежности
- Эмуляция человеческого поведения

### Рекомендации:
- Используйте задержки не менее 10 секунд между регистрациями
- Не регистрируйте более 50 аккаунтов в день
- Используйте разные IP-адреса при массовой регистрации
- Соблюдайте условия использования Roblox

## ⚠️ Важные замечания

1. **Только для образовательных целей** - этот генератор создан для изучения автоматизации
2. **Соблюдайте условия использования** - автоматическая регистрация может нарушать ToS Roblox
3. **Используйте ответственно** - не злоупотребляйте автоматизацией
4. **Генерируемые данные случайны** - не гарантируется уникальность
5. **Успешность регистрации не гарантирована** - сайт может блокировать автоматизацию
