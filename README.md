# 💖 Telegram Бот для nikswiq 💖

Красивый и милый Telegram бот с кнопками и анимацией для вашей любимой!

## 🚀 Как запустить

1. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Запустите бота:**
   ```bash
   python bot.py
   ```

3. **Найдите вашего бота в Telegram** и отправьте команду `/start`

## ✨ Функции

- **Кнопка "У вас новое письмо"** - показывает красивое письмо с поддержкой
- **Кнопка "Показать анимацию"** - демонстрирует анимированные сердечки с подписью "ТВОЙ МУЖ, РОМОЧКА"

## 🎨 Особенности

- Красивое оформление с эмодзи
- Анимированные сердечки
- Трогательное письмо с поддержкой
- Простой и понятный интерфейс
