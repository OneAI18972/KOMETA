# 🌸 Sakura Art - Сайт для заказа артов по Roblox

Красивый и функциональный сайт для приема заказов на арты по тематике Roblox в стиле сакуры.

## ✨ Возможности

- 🎨 **Красивый дизайн** в стиле сакуры с анимациями
- 👤 **Система авторизации** с регистрацией и входом
- 📋 **Форма заказа** с различными опциями (стиль, тип, формат)
- 💼 **Личный кабинет** для отслеживания заказов
- 🖼️ **Портфолио** для демонстрации работ
- 📱 **Интеграция с Telegram** для связи с клиентами
- 📱 **Адаптивный дизайн** для всех устройств
- 🌸 **Анимация падающих лепестков сакуры**

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск сервера

```bash
# Обычный запуск
npm start

# Запуск в режиме разработки (с автоперезагрузкой)
npm run dev
```

Сайт будет доступен по адресу: `http://localhost:3000`

## 🛠️ Настройка

### 1. Telegram интеграция

Замените `yourusername` на ваш реальный Telegram username в следующих файлах:

- `public/index.html` (строки с `https://t.me/yourusername`)
- `public/login.html` 
- `public/portfolio.html`
- `public/profile.html`
- `public/js/main.js` (функция `showTelegramContact`)

### 2. Добавление работ в портфолио

Чтобы добавить примеры работ в портфолио, вставьте данные в базу данных:

```sql
INSERT INTO portfolio (title, description, image_path, category) VALUES 
('Персонаж в стиле сакуры', 'Красивый арт в розовых тонах', '/uploads/example1.jpg', 'single'),
('Парный арт', 'Романтическая сцена двух персонажей', '/uploads/example2.jpg', 'pair'),
('Групповой арт', 'Команда друзей', '/uploads/example3.jpg', 'group');
```

Поместите изображения в папку `public/uploads/`.

### 3. Настройка базы данных

База данных SQLite создается автоматически при первом запуске. Файл: `database.db`

## 🎨 Функциональность страниц

### Главная страница (`/`)
- Презентация услуг
- Описание типов артов
- Призыв к действию

### Портфолио (`/portfolio`)
- Галерея работ с фильтрацией
- Описание процесса создания
- Информация о том, что входит в заказ

### Регистрация (`/register`)
- Форма создания аккаунта
- Валидация данных
- Информация о преимуществах регистрации

### Вход (`/login`) 
- Форма авторизации
- Ссылка на Telegram для прямой связи

### Заказ (`/order`) - только для авторизованных
- Выбор стиля арта
- Выбор количества персонажей
- Выбор формата
- Подробное описание пожеланий
- Информация о сроках

### Профиль (`/profile`) - только для авторизованных
- Статистика заказов
- Список всех заказов с фильтрацией
- Контактная информация

## 🔧 API Endpoints

### Аутентификация
- `POST /api/register` - Регистрация
- `POST /api/login` - Вход
- `POST /api/logout` - Выход  
- `GET /api/auth-status` - Проверка статуса

### Заказы
- `POST /api/order` - Создание заказа
- `GET /api/my-orders` - Получение заказов пользователя

### Портфолио
- `GET /api/portfolio` - Получение всех работ

## 🚀 Развертывание

### На VPS/VDS сервере

1. Загрузите проект на сервер
2. Установите Node.js
3. Установите зависимости: `npm install`
4. Запустите: `npm start`
5. Настройте reverse proxy (nginx) при необходимости

### С использованием PM2

```bash
npm install -g pm2
pm2 start server.js --name "sakura-art"
pm2 startup
pm2 save
```
